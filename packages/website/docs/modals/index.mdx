# Modal

The `Modal` component provides a simple imperative API to display dialog
windows. Use `Modal.show()` to create modals programmatically.

## Modal.show()

The primary method for displaying modals. It accepts content and modalOptions,
and returns a controller for managing the modal.

```tsx
Modal.show(content, modalOptions);
// or
Modal.show(modalOptions);
```

<DocBlock>
<DocDescription>
### Basic Usage

The simplest way to show a modal is to pass a string or ReactNode as content and
an optional options object with a `title`.

</DocDescription>
<DocSample>
<SamplePreview><BasicModalSample /></SamplePreview>

```tsx
import { Modal } from 'react-dialogues';

Modal.show('Hello! This is a basic modal.', { title: 'Basic Modal' });
```

</DocSample>
</DocBlock>

<DocBlock>
<DocDescription>
### Rich Content

You can pass JSX elements as content for more complex layouts. Use the `content`
property in the options object.

</DocDescription>
<DocSample>
<SamplePreview><ModalWithContentSample /></SamplePreview>

```tsx
import { Modal } from 'react-dialogues';

Modal.show({
  title: 'Rich Content',
  content: (
    <div>
      {' '}
      <p>
        {' '}
        This modal contains
        <strong>rich JSX content</strong>.{' '}
      </p>{' '}
      <ul>
        {' '}
        <li>Item one</li> <li>Item two</li>
      </ul>{' '}
    </div>
  ),
});
```

</DocSample>
</DocBlock>

<DocBlock>
<DocDescription>
### Custom Buttons

Customize modal buttons using the `buttons` array. You can use the built-in
`OkButton` and `CancelButton` components or create your own.

**Button options:**

- String values: `'OK'`, `'Cancel'`
- Components: `<OkButton />`, `<CancelButton />`
- Custom JSX elements

</DocDescription>
<DocSample>
<SamplePreview><ModalWithButtonsSample /></SamplePreview>

```tsx
import { Modal, OkButton, CancelButton } from 'react-dialogues';

Modal.show({
  title: 'Confirm Action',
  content: 'Are you sure you want to proceed?',
  buttons: [<CancelButton />, <OkButton />],
});
```

</DocSample>
</DocBlock>

<DocBlock>
<DocDescription>
### Size Options

Control the modal width with the `size` property.

**Available sizes:**

- `'normal'` - Default size (default)
- `'large'` - Wider modal for more content
- `'full'` - Full-screen modal

</DocDescription>
<DocSample>
<SamplePreview><ModalSizesSample /></SamplePreview>

```tsx
import { Modal } from 'react-dialogues';

// Normal size (default)
Modal.show({ title: 'Normal', content: '...' });

// Large size
Modal.show({ title: 'Large', content: '...', size: 'large' });

// Full screen
Modal.show({ title: 'Full', content: '...', size: 'full' });
```

</DocSample>
</DocBlock>

<DocBlock>
<DocDescription>
### Centered Position

By default, modals appear near the top of the screen. Use `centered: true` to
vertically center the modal.

**Options:**

- `centered` - Boolean, centers modal vertically when `true`

</DocDescription>
<DocSample>
<SamplePreview><ModalCenteredSample /></SamplePreview>

```tsx
import { Modal } from 'react-dialogues';

// Default position (top)
Modal.show({ title: 'Default', content: '...' });

// Centered vertically
Modal.show({ title: 'Centered', content: '...', centered: true });
```

</DocSample>
</DocBlock>

<DocBlock>
<DocDescription>
### Async/Promise Handling

`Modal.show()` returns a controller that is also a Promise. Use `await` to get
the user's action when the modal closes.

**Return value:**

- `[action, result]` - Tuple with the action name and result value
- `action` is typically `'ok'`, `'cancel'`, or `'close'`

</DocDescription>
<DocSample>
<SamplePreview><ModalAsyncSample /></SamplePreview>

```tsx
import { Modal, OkButton, CancelButton } from 'react-dialogues';

const [action] = await Modal.show({
  title: 'Async Example',
  content: 'Click OK or Cancel.',
  buttons: [<CancelButton />, <OkButton />],
});

if (action === 'ok') {
  // User clicked OK
}
```

</DocSample>
</DocBlock>

## API Reference

### Modal options

| Property       | Type                            | Default    | Description                     |
| -------------- | ------------------------------- | ---------- | ------------------------------- |
| `buttons`      | `DialogButton[]`                | `['OK']`   | Array of buttons                |
| `centered`     | `boolean`                       | `false`    | Center modal vertically         |
| `className`    | `string`                        | -          | CSS class for modal             |
| `closeOthers`  | `boolean`                       | `false`    | Close other modals when opening |
| `content`      | `ReactNode`                     | -          | Modal body content              |
| `mask`         | `boolean`                       | `true`     | Show background overlay         |
| `maskClosable` | `boolean`                       | `true`     | Click overlay to close          |
| `onClose`      | `(result) => void`              | -          | Called when modal closes        |
| `size`         | `'normal' \| 'large' \| 'full'` | `'normal'` | Modal width                     |
| `title`        | `ReactNode`                     | -          | Modal header title              |

### Inherited from DialogProps

These properties are inherited from the base `Dialog` component:

| Property     | Type                                         | Default | Description                                     |
| ------------ | -------------------------------------------- | ------- | ----------------------------------------------- |
| `actionMode` | `'okClose' \| 'simplified' \| 'full'`        | -       | Controls how button actions resolve the promise |
| `body`       | `ReactNode`                                  | -       | Direct body content (bypasses content wrapper)  |
| `classNames` | `Partial<Record<ModalSlots, string>>`        | -       | CSS classes for internal slots                  |
| `close`      | `ReactNode`                                  | -       | Custom close button element                     |
| `component`  | `ComponentType`                              | -       | Custom component to render instead of Dialog    |
| `empty`      | `boolean`                                    | `false` | Render only content without header/footer       |
| `firstChild` | `ReactNode`                                  | -       | Content inserted before all other elements      |
| `footer`     | `ReactNode`                                  | -       | Custom footer element (overrides buttons)       |
| `header`     | `ReactNode`                                  | -       | Custom header element (overrides title)         |
| `icon`       | `ReactNode`                                  | -       | Custom icon element                             |
| `lastChild`  | `ReactNode`                                  | -       | Content inserted after all other elements       |
| `type`       | `'success' \| 'info' \| 'warning' \| 'error'`| -       | Notification type styling                       |

### Return Value

`Modal.show()` returns an `RdController` that implements
`Promise<[action, result]>`:

```tsx
const controller = Modal.show({ title: 'Example', content: 'Hello' });

// Promise methods
const [action, result] = await controller;

// Controller methods
controller.update({ title: 'Updated Title' }); // Update modal props
controller.destroy('cancel'); // Close modal programmatically
```
